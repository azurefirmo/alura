# 🎓 Alura & Oracle Next Education (ONE)

## 📖 Sobre este Repositório

Este repositório reúne as formações e cursos concluídos na plataforma **Alura**, por meio do programa **Oracle Next Education (ONE)**.

O objetivo é registrar a trajetória de aprendizado, as tecnologias estudadas e as competências desenvolvidas durante cada formação.
